## Entry point
Run `python a661_cds_logs_to_perf_charts.py` for a list of expected arguments.

## Requirements
- SCADE Solutions for ARINC 661
- Performance log files generated for timing, memory and network on the SCADE ARINC 661 server
- Python 3.10 or later
- matplotlib 3.10 or later - run `pip install -r requirements.txt`
